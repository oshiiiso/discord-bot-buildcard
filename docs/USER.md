# BuildCard-Bot 使い方

原神の UID を入れると、プロフィールに出しているキャラの聖遺物スコア入りカードをチャンネルに出す。

> **個人・身内利用向け**
> 信頼できるサーバーでのみ運用してください。ソースの使い方は基本的に自由です。動かしたい場合は [Issues](https://github.com/oshiiiso/discord-bot-buildcard/issues) か連絡をもらえればセットアップを補助します。

プログラムの起動やデータの置き場は [README.md](../README.md) を見てください。

---

## カードの出し方

1. ゲームのプロフィールで、**キャラクター紹介を公開**する
2. 「カードを出す」を押して UID を入れる
3. 出したいキャラを選んで「このキャラで出す」（自分にだけ見える。**所持キャラ全員ではなく、プロフィールに出しているキャラだけ**）
4. チャンネルにはカード画像だけ出る
5. 同じ一覧の別キャラは、出したあとの選択から続けて出せる。ゲーム側で出したキャラを直したら「紹介を取り直す」
6. カード画像の下にも「カードを出す」が付く。いちばん新しいカードの下が、次の人の入口

操作できるのは UID を入れた人だけ。古いカードのボタンは残るので、同時に何人やっても欠けない。選択は 15 分で消える。消えたあとは、カードのボタンかピン留めから UID を入れ直す。

## コマンド

引数なしは空欄のまま。

**誰でも（この Bot 用のチャンネル）**

| コマンド | 引数 | できること |
| --- | --- | --- |
| `/uid` | 原神の UID（8〜10桁） | ボタンの代わりにカードを出す |
| `/formula` | | 点数の見方 |
| `/ping` | | 応答確認 |

**メッセージの管理がある人**

| コマンド | 引数 | できること |
| --- | --- | --- |
| `/setup` | | 案内をピン留めする |
| `/reload` | | 新しいパッチのあと、キャラの名前と立ち絵を取り直す |
| `/check` | | 覚えている全キャラの立ち絵名・ビルドが足りるか見る |
| `/addchar` | 下の表 | このキャラの点数の出し方・名前を覚える |
| `/addset` | 下の表 | この聖遺物セットを「定番」判定できるようにする |

`/addchar` の引数:

- `name` … 日本語の名前
- `number` … キャラの番号（数字 8〜10 桁）
- `element` … 炎 / 水 / 氷 / 雷 / 風 / 岩 / 草
- `scale` … 点数の出し方（攻撃 / HP / 防御 / 熟知 / チャージ）
- `aliases` … 別名（任意。カンマ区切り。立ち絵が欠けるときは英名も）

`/addset` の引数:

- `name` … セットの日本語名
- `set_id` … セットの短い英語名（英小文字と `_`）
- `aliases` … 別名（任意）

番号やセット ID の調べ方は README を見てください。

## 攻撃・HP・防御を選ぶとき

Bot がまだ **このキャラの点数の出し方を覚えていない** ときだけ、攻撃 / HP / 防御 / 熟知 / チャージ から選ぶ。

覚えているキャラは、登録してあるビルドだけ（胡桃ならビルド選択なし。甘雨なら「凍結」「溶解」などを選んでから出す）。攻撃・HP の5択にはならない。

毎回選ばせたくない、防御で点数を出したい、というときが `/addchar`。

---

## 一覧に出るか、立ち絵が足りるか

**出したいキャラが一覧にあるか** は、UID を入れて見る。あればプロフィールに出している。`/check` では分からない。

`/check` は「Bot が覚えている全員」の確認。**名前・立ち絵がまだ古い** は、公式の名前や立ち絵がまだ追いついていない、という意味。カードは出せることが多い。見た目や点数の出し方を固定したいときだけ `/addchar`。

聖遺物セットに専用の確認コマンドは無い。**カードにセット名が出ていれば名前は取れている。** 点数も出る。「定番」と出ないときだけ `/addset`。

---

## パッチのあと

1. `/reload`
2. `/check`（立ち絵名と「名前・立ち絵がまだ古い」を見る）
3. 毎回 攻撃・HP などを選ばせたくないキャラ、名前や立ち絵が欠けているキャラ → `/addchar`
4. カードにセット名は出るが「定番」にならない → `/addset`

一覧に出ているキャラは、`/addchar` なしでもカードは出せる。プロフィールに出していないキャラは、カードにできない。

## Discord に置くとき

1. [Discord Developer Portal](https://discord.com/developers/applications) で Bot を作る。名前は **BuildCard-Bot**
2. OAuth2 URL Generator で `bot` と `applications.commands` を選ぶ
3. 権限の例: メッセージを見る / 送る、埋め込みリンク、メッセージ履歴を読む、メッセージの管理（ピン留め）、ファイルを添付
4. サーバーに招待する（MESSAGE CONTENT INTENT は不要）
5. README のとおり起動し、対象チャンネルで `/setup`

`.env` に入れるもの:

- `DISCORD_TOKEN` … Bot トークン
- `GUILD_ID` … サーバー ID（推奨。スラッシュがすぐ出る）
- `CHANNEL_ID` … この Bot を置くテキストチャンネル（スレッド不可）

## うまくいかないとき

- カードが空 … キャラクター紹介が非公開、または出したキャラがいない
- ゲーム側で出したキャラを直しても古い … 選択の「紹介を取り直す」。反映が少し遅れることもある
- 開始ボタンが動かない … Bot が落ちていないか。起動中ならピンも過去の開始ボタンも効く
- ピン留めできない … 対象チャンネルで Bot に「メッセージの管理」があるか。チャンネル個別の権限で落ちていることが多い。案内自体は出せるので、権限を付けて `/setup` し直す
- カードが出せない … README の手順で起動しているか
- 立ち絵やアイコンが出ない … パッチ直後は `/reload` のあと、**もう一度ボタンからカードを出す**。まだ欠けていて名前や点数の出し方を固定したいなら `/addchar`（別名に英名）
